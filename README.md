# 🧹 电脑清理扫描器 (PC Clean Scanner)

> 只扫描、只出报告，**绝不删除任何文件**——帮你回答「电脑里有什么、哪些能删、哪些要留」。

## ✨ 功能

每次想整理电脑时运行一次，生成一份可交互的网页清理报告：

| 标签页 | 内容 |
|---|---|
| 💾 磁盘与对比 | 各分区容量/剩余空间 + **与上次扫描自动对比**（清理效果一目了然） |
| 🧽 清理点 | 按 A/B/C 安全等级分级的可清理位置及体积，附具体清理建议 |
| 🔁 重复文件 | 按内容哈希检测（双重校验不误报），标出每组保留/可删副本 |
| 📦 项目依赖目录 | 扫出所有 node_modules / venv / target / __pycache__ |
| 🪀 已安装程序 | 注册表级程序清单：分类/版本/厂商/体积/卸载命令 |
| 🐘 大文件排行 | 占空间最大的文件排行，快速定位"空间大户" |
| 📁 文件夹体积 | 各目录大小排行，看"空间都去哪了" |

**报告交互**：点击列头排序 · 关键字实时筛选 · 勾选清理项导出清理脚本（移入回收站，可撤销）

**清理点分级**：
- **A 级 · 放心清理**——缓存/临时文件（浏览器缓存、Temp、崩溃转储等 30+ 类）
- **B 级 · 确认后清理**——可能含个人内容（下载、微信文件、AI 模型缓存、Docker/WSL、Gradle/Maven 等），删前看一眼
- **C 级 · 谨慎/仅了解**——系统关键/个人数据，只统计体积不建议动

## 📥 下载安装

1. 进入 [Releases 页面](../../releases)，下载最新的 `电脑清理扫描器.exe`（约 12 MB）
2. 放到任意文件夹（建议固定位置如 `D:\工具\清理扫描\`），双击即可运行
3. 首次运行如遇 SmartScreen/杀毒提示，选「仍要运行/信任」（新打包 exe 的正常现象）

**环境要求**：Windows 10/11 64 位。**无需安装 Python** 或任何依赖，单文件即用，可拷贝到 U 盘在任意 64 位 Windows 电脑上运行。

想看更全的系统目录统计（如 C:\Windows\Temp）：右键 exe → 以管理员身份运行。

## 🖥️ 使用

双击 exe 弹出图形界面：勾选扫描选项 → 「开始扫描」→ 完成后「打开报告」或「手机扫码查看」（同一 WiFi）。

报告自动存到 exe 旁的 `scan_reports\日期时间\`，包含：
- `清理扫描报告.html` —— 主报告（浏览器打开）
- 6 份 CSV 明细（程序清单/清理点/大文件/文件夹体积/项目依赖目录/重复文件）

### 命令行（进阶）

```bat
电脑清理扫描器.exe --full                 全盘扫描（所有本地硬盘）
电脑清理扫描器.exe --min-size 2GB         大文件门槛（默认 100MB）
电脑清理扫描器.exe --dup-min 50MB         重复文件门槛（默认 10MB）
电脑清理扫描器.exe --no-duplicates        跳过重复文件检测
电脑清理扫描器.exe --set-report-dir "E:\报告"   自定义报告位置（记住）
电脑清理扫描器.exe --console              强制控制台模式
```

### 从源码运行（开发者）

```bash
git clone https://github.com/UltraSkyShow321/pc-clean-scanner.git
cd pc-clean-scanner
python pc_clean_scanner.py          # 需 Python 3.8+，纯标准库零依赖
```

从源码构建 exe：

```bash
pip install pyinstaller segno
pyinstaller --onefile --noconsole --name 电脑清理扫描器 --icon assets/app-icon.ico pc_clean_scanner.py
```

## 🔒 安全设计

- **只读扫描**：全程不写、不删任何被扫描的文件
- **删除权在你**：报告只是清单；导出的清理脚本把文件**移入回收站（可撤销）**而非直接删除，且运行前有路径清单供审阅
- **跳过符号链接**：避免重复统计和误跟联接点
- **纯本地**：扫描结果不上传任何服务器；手机查看走局域网直连
